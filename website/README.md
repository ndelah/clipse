# Clipse website

Static product site and privacy policy for https://clipse.delahousse.xyz.

- `dist/index.html`: landing page in the forest/cream/lime promo identity.
- `dist/privacy/index.html`: privacy policy, with canonical URL `/privacy`.
- `dist/site.js`: accessible example tabs; no analytics or API calls.
- `dist/assets/`: locally served branding, actual extension UI examples, Remotion demo, and caption track.
- `.openai/hosting.json`: Sites identity and static hosting manifest.

The site links to the published [Chrome Web Store listing](https://chromewebstore.google.com/detail/clipse/fdaodlknpokllhkeiolemcghghejhmbp) from the navigation, hero, getting-started FAQ, and closing section.

The privacy policy describes the reviewed 0.8.0 implementation, local data and Undo retention, provider processing, keys and deletion, website hosting, and Limited Use. Keep it synchronized with future extension changes. Support contact uses the developer's existing account address.
