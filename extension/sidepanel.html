A few things to know

What’s an API, and why do I need a key?

An API lets Clipse ask an AI service to process a video’s captions. Your API key connects those requests to your account.

Clipse is free to use, but AI processing can cost money. I don’t cover users’ API costs, so you bring your own key and pay the provider directly. A ChatGPT subscription doesn’t include OpenAI API usage.

How do I connect OpenAI?
  1. Sign in to the OpenAI API platform ↗ and create a secret key.
  2. Set up API billing ↗ and make sure you have available credit.
  3. Paste it above and choose Connect and continue.

Clipse checks summaries and classification before saving your key. These checks make small paid API requests.

Is my data safe?

Your API key, settings, and summary history stay locally in this Chrome profile. Clipse has no developer server or analytics: I can’t see your keys, videos, or summaries.

To create a summary, captions and video metadata go directly to OpenAI. OpenAI processes that data under its own policies; the AI processing isn’t local.

Your key is only sent to OpenAI and is excluded from history backups.
