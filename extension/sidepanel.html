A few things to know

What’s an API, and why do I need a key?

An API lets Clipse ask an AI service to process a video’s captions. Your API key connects those requests to your account.

Clipse is free, with no Clipse subscription. Bring your own API key and pay your AI provider directly for what you use. OpenAI API usage is billed separately from ChatGPT.

How do I connect OpenAI?
  1. Sign in to the OpenAI API platform ↗ and create a secret key.
  2. Set up API billing ↗ and make sure you have available credit.
  3. Open Clipse’s Settings, paste it into OpenAI API key, and choose Save settings.

Clipse checks key and model access before saving a new key. This check cannot verify your credit balance.

How do I connect Jev?

Jev, by TypeSafe, is optional. It classifies videos; OpenAI still writes the summaries. You can use Clipse with just an OpenAI key.

  1. Sign in to the TypeSafe console ↗ and create an API key. Set up any billing or access required by TypeSafe.
  2. In Clipse’s Settings, set Video classification to Jev · TypeSafe.
  3. Paste your key into TypeSafe API key and choose Save settings.
Is my data safe?

Your API keys, settings, and summary history stay locally in this Chrome profile. Clipse has no developer server or analytics: I can’t see your keys, videos, or summaries.

To create a summary, captions and video metadata go directly to OpenAI. If you select Jev, caption excerpts and metadata also go to TypeSafe. These providers process that data under their own policies; the AI processing isn’t local.

Keys are only sent to their respective provider and are excluded from history backups.
